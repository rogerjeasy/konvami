# Additional target languages (§13)

English, French and Italian use the existing LanguagePack boundary. Each has eight curated grammar notes/topics across A1–C2, three pronunciation contrasts with guidance in all four interface languages, eight role-play situations, three starter partners, a voice sample and regular-inflection matching. This is starter reference content, not an exhaustive curriculum or an official exam course.

Administrative role-plays reuse their goal ids and ask about the country before describing local obligations. No German-style address registration is assumed outside German. No invented exam formats are added: the profile rejects Goethe/telc goals for these packs.

Cards validate dictionary articles per target language. Verb-form prompts use the target language's tenses. German gender-colour conventions apply only to der/die/das. Spoken review recognizes a missing article, including elided l', without treating it as a fully unknown word. Conversation review and the live word checklist use corresponding regular-inflection rules; neither claims to recognize every irregular form.

The provider and account boundaries are unchanged. Text generation and transcription already use the target language selected in the profile. The placement-tool description no longer assumes German. Existing German tests remain regression coverage.
